# MongoDB 索引设计器集成记录

这是下一里程碑的独立实现记录，尚不表示三平台完整索引工具或 1:1 UI 验收完成。
参考为本机 Navicat Premium 18.0.5 build 321，实际界面观察见
[M18-07](ui-reference-18-mongodb.md)。所有写入测试使用新建的一次性 MongoDB 服务及生成数据。

## 已接入的工作流

索引对象列表使用名称、索引类型、集合名称、唯一键、背景、稀疏、到期秒数、版本、大小九列。
大小来自服务器的 `collStats.indexSizes`；无法取得的值显示为空缺，不伪造零。
对象表格双击、设计按钮和连接树入口均打开独立索引文档。同一数据库内不同集合的同名索引分别定位；
页面未保存的目标集合修改不会改变其原对象身份。

设计器有常规、存储引擎、排序规则、文本、地理空间、脚本预览六页，保留键顺序及 BSON 类型。
新建时保存窗口要求名称，并显示最终脚本；取消不会写数据库。
删除窗口要求勾选永久删除确认。只读连接及 `_id_` 等受保护对象可查看，不能修改。
更改/DDL 中的 `createIndex`、`dropIndex` 辅助脚本可复制到原生 mongosh 执行。
实际执行页另显示带集合 UUID 与确认写关注的命令，以及精确 BSON 诊断；这部分表示本实现的保护措施，
不声称参考包含相同控件。

普通保存确认最终计划后，数据库工作在主窗口的单一串行队列运行；取消使用单独的工作线程。
执行前取消不发送 DDL。执行中停止只针对点击时捕获的本次 MongoDB 操作身份，不取消后来开始的操作。
数据库 I/O 不读取 Qt 控件，结果回到 GUI 后再次检查页面、会话和预览版本。
保存成功刷新对象列表和导航，不覆盖其他已打开文档的未保存内容。
关闭标签、断开连接或退出窗口时，保存完成后才继续相应动作；取消保存保留原页面。

重启仅保存连接、数据库、集合、索引名四项对象引用，不保存已确认命令、BSON 快照或签名。
恢复的索引页面先保持断开；用户明确连接后重新读取当前定义。
完整标签顺序、焦点、布局与所有类型文档恢复仍属于 U17 的未完成范围。

## 保存预览偏好实测

补充观察仍使用上述实际参考版本及自建临时集合：初始“保存之前显示 SQL 预览”为开启。
在已有索引保存窗口勾选“不再显示脚本预览”后取消，偏好不变；勾选并实际保存后，偏好关闭。
随后保存同一已有索引的另一项修改不再出现预览窗口，独立读取确认修改实际生效。
参考的原偏好已在界面中恢复开启，临时数据库对象已按身份核对后清理，原样例文档和索引未改变。
最后关闭设置窗口并回到原标签的界面恢复操作发生工具超时，最终窗口/标签位置未确认。
没有把该界面恢复状态当成已验证。

OpenNavicat 只有接受保存窗口时才持久化该偏好，并同步到已打开的对象设计器。
已有 MongoDB 索引在关闭预览时对捕获的当前草稿重新生成并执行计划。
参考的跨数据库驱动作用域、重启、保存失败和新建索引关闭预览后的行为尚未完整观察，继续保留对照任务。

## 非事务 DDL 与实际状态

MongoDB 修改索引通常需要删除后重新创建，两步不是事务。
集合 UUID 用于防止预览后集合被删除并以同名替换；它不提供索引定义的原子比较并交换。
执行前检查原索引及目标名称，执行时使用 UUID 限定的服务器命令。
并发索引修改仍存在检查与执行之间的竞争窗口，不承诺原子 DDL。

如果删除已确认而创建失败，界面保留草稿，并分别显示每一步是未执行、服务器已确认、服务器报错还是确认未知，
同时显示重新读取的实际索引状态。网络确认丢失不解释成“没有修改”，不自动重试或回滚。
失败后也刷新对象列表，避免仍显示已被删除的旧索引。

创建/删除命令的 UUID 保护已在自有 MongoDB 7.0.45、8.0.34、8.2.12 做非空命令资格检查；
7.0.45 仅是该协议检查，不改变当前会话适配器的最低版本边界。
无副作用的空命令探测在不同服务器版本返回不同错误；只接受已核实的命令特定结果，
未知结果拒绝保存，不退回不带 UUID 的写入。版本范围资格尚未穷尽。

## 验证与剩余范围

`test_mongodb_indexes.py`、`test_mongo_index_designer_ui.py`、`test_mongodb_index_script.py`
验证真实服务器上的类型、计划绑定、并发替换、部分失败、取消、辅助脚本和保护命令复制执行。
`test_mongo_index_window.py` 验证主窗口的完整接线，包括两个集合的同名索引、键顺序、保存/取消、删除确认、
未保存文档保护、失败后实际状态、排队/执行中停止、关闭前保存、只读与断开恢复。
协议 runner 将这些模块与既有 MongoDB 会话、查询、文档和 GridFS 模块一同执行，并要求零跳过及精确 fixture 清理。

原始元数据使用 Raw BSON 读取；未知选项或无法无损表达的脚本值保留原字节并只读，不猜测和转换类型。
这是一项明确的实现边界，不能据此关闭完整索引功能：尚需完成未知选项/类型编辑、全部服务器与拓扑、权限/断线、
管理组、键表格全部交互、视觉细节以及三平台实际参考和安装包验收。
其他驱动索引、MongoDB 集合设计器及其他专属工具仍按总矩阵推进。
