## 候选变化

- 普通集合设计器按本机 Navicat 18.0.5 的实际观察排列七个页签，默认进入索引页；
  内嵌列表隐藏服务器维护的 `_id_`，独立索引工具和真实元数据仍保留它。
- 两个集合级存储脚本页支持已验证的 WiredTiger `storageEngine` 与 `indexOptionDefaults` 文档，
  提供有界字面量编辑、脚本预览、保存确认、取消、服务器错误重试和重开。
  实际字段形状为 `indexOptionDefaults.storageEngine.wiredTiger.configString`，不会把未知字段静默转成其它配置。
- 增加普通集合创建/设计、删除/清空/重命名、staged 结构或结构数据复制、验证/reIndex/compact，
  以及已实现的时序集合、普通视图设计和元数据信息区。各工具的适用条件与边界见 [集合设计说明](https://github.com/shubolab/opennavicat/blob/main/docs/mongodb-collection-designer-backend.md)。
- 非法草稿的预览错误留在编辑器内；关闭/断开时校验失败不会遗留随后误触发的保存 continuation。
  数据库工作继续由串行后台队列执行，取消使用单独 worker。
- 加入保持原始 BSON、类型/顺序和未知规则的原子验证器草稿模型。
  它目前是后端基础，**尚未成为完整 Schema/Query 可视 builder**。
- Linux 依赖准备在保持 Ubuntu archive 签名与 TLS 的前提下提供隔离的 TUNA 回退，
  并预装实际 DEB 全部依赖组，继续保留安装、运行、卸载、字体和原生架构门禁。

## 已知边界

两个存储选项目前为普通集合 create-only；已有集合只读显示并保持原值，不做 drop/recreate。
WiredTiger 配置字符串由服务器判定，当前已验证的形状不等于全部引擎、加密、时间序列存储或服务版本已经支持。
未知配置和不能精确编辑的 BSON 保留完整原始字节并只读显示。

集合 UUID 用于身份保护，不是选项或索引定义的原子 CAS。创建成功可能对应最终检查后由其它客户端创建的同配置集合，
不据此宣称独占归属；已确认操作不会自动撤销，丢确认、取消或部分失败也不自动重试。
复制保留 staging 与非快照/非事务边界，不覆盖已存在目标。

当前内嵌索引仍使用已有独立索引工具入口；原版的行内索引/键编辑、完整验证器、全部高级集合与排序规则控件，
以及 Windows/Linux 原版 UI 逐项对照仍未完成。七个页签、源码测试或六安装器均不能替代这些功能验收。
