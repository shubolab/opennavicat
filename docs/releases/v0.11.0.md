# OpenNavicat v0.11.0 候选

**尚未发布；本版六个原生安装器、正式 tag 和公开资产验收仍待完成。**
当前公开版本仍为 [v0.10.0](https://github.com/shubolab/opennavicat/releases/tag/v0.10.0)。

本版推进 MongoDB 集合与聚合工具，并加入已保存管线的本地批处理工作流。

- 集合工具继承 main 中的行内索引/键编辑、结构化排序规则与152个locale、集合选项、
  可视管线、Options、`.nagg`文件和视觉Explain等已实现片段。
- 自动运行提供全局作业列表及常规、高级、消息日志、历史四页。
  已保存的MongoDB管线可重复加入并顺序执行，支持遇错继续/跳过、本地保存重开及持久运行历史。
  每个任务使用独立会话，交互连接保持原状态；开始时冻结最新保存内容，重命名后旧引用明确失效。
- 修复管线生成脚本的aggregate参数及BSON类型、连接树入口、保存后名称和已载入stage编辑；
  简化表单不能无损表示时保留原始编辑器。
- 取消通过独立worker和精确操作标记执行。已完成或确认未知的数据库效果不会自动撤销或重试。
  历史写盘失败保留结果与待保存记录，重试仅补写未确认的历史。

本机0.11工作树：默认全源 **2011通过 / 567条件跳过**；MongoDB专项 **460项零跳过**，
八个独有原生MongoDB8.0.34 fixture逐精确ID确认清理；原生Cocoa **51项零跳过**。
唯一真实应用GIF已更新为 **28阶段、371帧、61.84秒**，逐阶段隐私审核通过；批处理两次独立真实执行、
历史落盘和源BSON/UUID未变均已核验。不同验证范围重叠，不相加；本机检查不替代六目标安装器门禁。
完整证据及归属见 [0.11验证记录](https://github.com/shubolab/opennavicat/blob/main/docs/validation-0.11.md)。

计划交付Windows Setup EXE、Linux DEB、macOS DMG，各含amd64与arm64六份实际原生安装器，
并提供SHA256SUMS和build-manifests.json；仅在全部构建、安装、运行、卸载和摘要通过后发布。
当前分发策略没有发布者签名或Apple公证；Windows ARM64引导器为x86，应用及原生依赖须为ARM64。

当前可执行批任务只覆盖已保存MongoDB管线。其余15类工作、完整copy/group/文件管理、Scheduler、
SMTP/附件、退出后执行、离线与重启恢复、change-stream功能及全部三平台参考UI仍在完整目标范围内。
本版不代表完整Navicat数据库工具或1:1界面验收；[parity matrix](https://github.com/shubolab/opennavicat/blob/main/docs/parity-matrix.md)继续保留全部门禁。
产品账号/授权/云账号协作的既定排除不影响数据库认证、用户/角色/权限、云数据库连接及独立AI工具。
