# OpenNavicat v0.12.0

本版推进 MongoDB 聚合管线的有限 change-stream Run、按实际参考呈现的消息界面和当前页取消。

- 同一个游标读取已有事件及非空批次，在首次空批或明确边界结束。保留用户显式的
  resume/fullDocument 选项；限制行数、原始 BSON、渲染字节与协作时限，不自动重开或恢复流。
- 按 macOS Navicat Premium 18.0.5 的运行观察切换页签：忙时两页，空结果后三页，
  取得事件后四页，错误/停止后三页。消息和输出显示脚本、状态及实际耗时；后台事件保持精确 BSON。
- 当前页 Stop 绑定本次作业、会话和操作标记，使用独立取消 worker，覆盖排队、冷连接和执行中取消。
  迟到 Stop 不掩盖已经完成的错误，也不取消下一项操作；清理失败保留明确错误。
- Batch 可执行已保存的有限 stream 引用，主连接断开时仍用独立会话顺序执行并记录历史。
  行数、时间、字节边界不会记作无条件成功，部分事件与凭据不进入批任务日志或历史。
- stream 使用独立的 no-retry 客户端，保留有限网络等待及原 TLS/SSH 校验。
  owner 按精确 nonce 清理自己的游标，初次未取得句柄或清理未确认时保留明确状态。
- 连续执行后台任务后，在 GUI 线程释放已完成的任务信号和回调，避免长期保留完成对象。
- owned 测试清理严格核对本次身份、独占匿名卷和回执；显式或继承挂载在删除前拒绝。

本版发布门禁要求 Windows Setup EXE、Linux DEB、macOS DMG 各 amd64/arm64 六个原生目标，
分别构建、测试、安装、运行、卸载并核对摘要，再公开完整八资产集合。
实际冻结源码、测试及安装器证据见 [0.12验证记录](https://github.com/shubolab/opennavicat/blob/main/docs/validation-0.12.md)。
安装包当前没有发布者签名或 Apple 公证；Windows ARM64 安装引导器为 x86，应用及原生依赖为 ARM64。

当前有限 Run 不代表完整 change-stream 工具或三平台 UI 对齐。原版阶段预览/预览全部的两次故障
不作为期望行为复制；正常预览、全部流选项/权限/拓扑、持续 watch 适用性及平台参考仍开放。
其余 Batch 类别、Scheduler、SMTP、全部数据库工具和 1:1 UI 继续由
[完整矩阵](https://github.com/shubolab/opennavicat/blob/main/docs/parity-matrix.md)追踪，完整 goal 保持 active。
