# OpenNavicat v0.13.0

候选说明：本版本尚未公开发布，六目标安装器与正式发布门禁仍需完成。

本版加入 Oracle 专属连接与表、视图浏览路径，继续推进完整 Navicat 18 工具和界面还原。

- 按 macOS 18.0.5 实际观察重建 Oracle 连接的常规、高级、数据库、SSH、备注五页，
  保留 Basic/TNS、service/SID、角色、OS 认证、字符集和高级设置草稿。
- 当前可执行 Basic、service name、Default 角色、密码认证、普通 TCP 路径。
  尚未支持的活动设置在连接前明确拒绝，不改成其他认证或静默忽略。
- 保存设置后保持断开；不保存密码时，测试和每次打开分别取得临时密码，
  不写回配置或本地密码缓存。持久密码仍只使用操作系统 keyring。
- 接通 schema、28 列表对象和 13 列视图对象列表，以及有界、限定 owner 的只读数据页。
  NUMBER 使用 Decimal 交付；未知总行数和不可用元数据明确显示，不制造统计值。
- 数据库操作和关闭保持在串行 worker；Stop 使用独立 worker 和本次操作标记，
  防止迟到取消影响下一操作。服务器计算查询的取消与连接复用分别验证。
- 删除连接配置等待异步关闭成功；关闭失败或配置已替换时保留配置与凭据设置。
- 按实际 Navicat 18 观察重绘主栏、九驱动、供应商和小动作图形，调整各位置的尺寸、
  连接/开关/禁用状态及高分屏显示；修正页签关闭符号与控件释放。完整视觉门禁仍开放。
- 补充 MongoDB update/fullDocument 和集合 pre/post-image 的实际运行回归；
  两类 required-image getMore 47 错误按已观察的界面显示 0/0 提示，真实脚本坐标继续独立保留。

发布门禁要求 Windows Setup EXE、Linux DEB、macOS DMG 各 amd64/arm64 六份原生安装器，
逐目标构建、测试、安装、启动、卸载和核对摘要；Oracle 原生驱动探针及两个原生 Linux
自有 Oracle 后端、窗口专项均为必需门禁。安装包当前没有发布者签名或 Apple 公证；
Windows ARM64 安装引导器为 x86，应用及原生依赖为 ARM64。

这是有限功能里程碑。Oracle Query、事务、写入、设计器、Data Pump、15 类 Other 工具及
其余认证、安全、高级设置、全部类型仍未验收；及时取消 server-side SLEEP 也仍有已记录限制。
其余数据库工具、MongoDB 完整流预览/恢复及 Windows/Linux/macOS 的完整参考 UI 与人工验收，
继续由[完整矩阵](https://github.com/shubolab/opennavicat/blob/main/docs/parity-matrix.md)追踪。
各独立验证范围见[Oracle 候选记录](https://github.com/shubolab/opennavicat/blob/main/docs/validation-oracle-0.13-candidate.md)；
完整 goal 保持 active。
