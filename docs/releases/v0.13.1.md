# OpenNavicat v0.13.1

本里程碑加入 Oracle 连接与只读表、视图浏览，并按 Navicat 18.0.5 的实际画面继续对齐图标和小控件。

- 独立重绘主工具栏、对象树、九种数据库、供应商和常用动作图标，分别调整主栏、树、
  页签、查询选择器和连接网格的尺寸。连接、开关和禁用状态分别绘制，高 DPI 按实际尺寸重画。
- 页签关闭按钮使用灰色叉号，保留平台位置与执行、保存保护，并释放被替换的旧按钮。
- Oracle 常规端口框改为没有上下箭头的文本框；配置栏开关与新增配置按钮使用专用图形。
  修正父布局裁掉输入框右边缘的问题。无效端口在保存或连接前明确拒绝，TNS 隐藏草稿保留原值。
- MongoDB Atlas 与 Redis Enterprise Cloud 使用对应数据库图标，保留在数据库类型中；
  供应商筛选为十二项。完整连接选择器布局和所有别名仍有待逐项对照。
- Oracle 五页连接设置保留 Basic/TNS、service/SID、角色、OS 认证、字符集、SSH 和高级草稿。
  当前执行路径为 Basic、service name、Default 角色、密码认证、普通 TCP；不支持的活动设置
  在提示密码或连接之前明确拒绝。
- 保存连接后保持断开。不保存密码时，测试和每次打开分别取得临时密码；持久密码只使用
  操作系统 keyring。接通 schema、28 列表对象、13 列视图对象和限定 owner 的有界只读数据页，
  NUMBER 使用 Decimal，不制造未知行数或不可用元数据。
- 数据库操作和关闭使用串行 worker，Stop 使用独立 worker 与本次操作标记；删除配置等待
  异步关闭成功，失败或配置已被替换时保留原配置及凭据设置。
- README 保留一份由隔离生成数据录制的实际应用 GIF，并增加连接选择器画面。

`v0.13.0` 的正式 CI 失败，未发布安装器；旧 tag 和失败记录保留。本版须重新通过 Windows
Setup EXE、Linux DEB、macOS DMG 各 amd64/arm64 的六目标原生构建、测试、安装、启动、
卸载及摘要门禁，以及两个原生 Linux 架构的自有 Oracle 后端、窗口专项后才会发布。
安装包没有发布者签名或 Apple 公证；Windows ARM64 安装引导器为 x86，应用及原生依赖为 ARM64。

这是有限功能里程碑。Oracle Query、事务、写入、设计器、Data Pump、Other 工具及其余认证、
安全、高级设置、全部类型仍开放；server-side SLEEP 的及时取消也仍有限制。全部数据库工具、
MongoDB 完整流预览/恢复、所有小元素与对话框及三个操作系统的完整参考人工验收，继续由
[完整矩阵](https://github.com/shubolab/opennavicat/blob/main/docs/parity-matrix.md)追踪。
完整 goal 保持 active。
