# OpenNavicat v0.13.2

继续按 Navicat Premium 18.0.5 的实际控件观察对齐连接窗口和小图标。

- 新增独立绘制的绿圈白勾、蓝色复制图标和细关闭叉，区分裸加减、刷新与配置栏圈加号。
  结果条按实际 DPI 绘制，长状态和版本文字有界省略，字体随父窗口变化。
- SQLite 真实 Test 成功后，在设置区域显示绿色结果条、版本和成功连接线；配置栏标题与
  加号调整位置。修改设置、重测或失败时清除旧反馈，保留实际取消和保存按钮的原生顺序。
- Oracle 数据库页使用裸加减和刷新图标，保留草稿、回调和未实现功能的禁用状态；测试结果
  使用共享结果条，保留原有复制文本。没有据 SQLite 画面推定 Oracle 完整交互已验收。
- MongoDB GridFS 条件加减及执行计划详情关闭改用绘制图形；关闭或切换详情时释放旧场景
  控件，旧关闭信号不会关闭新详情。
- README 演示增加真实 SQLite Test。GIF 调色板分别保留九种驱动色和成功状态色，修正
  实际录制后成功圆点偏色的问题；使用新生成的隔离数据重新录制并检查。
- Oracle 自有测试服务在退出后停止无效重试，失败诊断只保留有限错误代码；日志捕获有
  大小、时间与进程组清理边界，不保存任意服务日志。原 CI ARM 退出 24 的根因仍未知。

发布门禁包括 Windows Setup EXE、Linux DEB、macOS DMG 各 amd64/arm64 的六目标原生
构建、测试、安装、启动、卸载及校验和，另有两个原生 Linux 架构的自有 Oracle 专项。
安装包没有发布者签名或 Apple 公证；Windows ARM64 安装引导器为 x86，应用及原生依赖为 ARM64。

这是有限功能里程碑。完整表单尺寸、全部小图标及状态、主题、菜单、向导和各平台实际参考
仍需继续对照。Oracle Query、事务、写入、设计器、Data Pump、其它认证与安全设置，以及
全部数据库工具功能和三平台完整人工验收继续由
[完整矩阵](https://github.com/shubolab/opennavicat/blob/main/docs/parity-matrix.md)追踪。
完整 goal 保持 active。
