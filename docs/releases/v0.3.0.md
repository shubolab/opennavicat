这是 OpenNavicat 的早期可用里程碑，提供 Windows、Linux、macOS 的 amd64 与 arm64 六份原生安装包。完整 Navicat UI 与工具功能仍在实现中。

- 按本机 Navicat 的实际界面重建主工具栏、连接树分类、对象列表、可选信息栏、SQL/结果区和连接表单。
- SQLite、PostgreSQL、MySQL、MariaDB 的连接、查询、多结果、事务、表数据编辑、CSV/JSON、有限数据比较及 SQLite 快照。
- PostgreSQL、MySQL、MariaDB 的 SSH 密码、私钥、密码和私钥组合认证、主机密钥固定、压缩及实际转发；TLS CA、客户端证书/密钥、加密密钥口令、CRL 和主机名验证。
- 数据库密码、SSH 密码、私钥口令和 TLS 密钥口令分别保存在进程或本机系统密钥服务。没有产品账号、登录、订阅和激活体系。
- 每个平台的安装包经过原生二进制架构检查、安装、实际应用/驱动 smoke 和卸载验证；`SHA256SUMS` 提供校验和，`build-manifests.json` 记录各平台的运行时与验证结果。Windows arm64 安装引导器可为 x86，安装后的应用及库为原生 arm64。

安装包：macOS 为 DMG（拖入 Applications），Windows 为当前用户 Setup，Linux 为 Debian/Ubuntu DEB。当前包未进行发布者签名或 Apple 公证。Linux arm64 要求 Ubuntu 24.04 或同等 glibc/Qt 运行环境；macOS 使用 Qt 6.12 的系统要求。

尚未完成的必需功能包括 Oracle、SQL Server、MongoDB，完整现有表/对象设计器、导入导出向导、结构/数据同步、HTTP 隧道、数据库用户与权限管理、自动运行、可编辑模型、图表及全部三平台 UI 对照。现有关系图和比较工具有明确边界，不能代表完整建模或同步能力。详见仓库的 `docs/parity-matrix.md`。
