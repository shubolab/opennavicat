这是以实际运行的 Navicat Premium 18.0.5 build 321 重新建立参考后的可用里程碑，
提供 Windows、Linux、macOS 各自的 amd64/arm64 六份安装包。完整工具功能和 1:1 UI 仍在继续实现。

- SQLite 新表与已有表使用独立设计标签，数据标签保持独立。包含字段、索引、外键、唯一键、
  触发器、选项和更改/DDL 预览，以及字段默认值、排序规则、生成列等属性。
- 新表命名和结构保存均先显示实际 SQL；后台完成元数据读取、规划和保存。关闭、断开和退出
  处理未保存草稿，取消或失败时保留编辑内容。
- SQLite 原地重命名与事务重建检查依赖、外键、数据、rowid、序列和并发 schema 变化。
  保留未编辑的原始约束和复杂索引；不支持的声明明确拒绝编辑。已有未提交数据记录时阻止结构保存。
- 工作台按18版观察更新 SQLite 索引/触发器类别、BI 名称、查询消息/摘要、结果位置与专注模式。
  尚未实现的独立索引/触发器对象列表、BI 和 AI 入口保持禁用，不能视为完整工具已实现。
- README 使用 OpenNavicat 自身连续录制的一段 GIF，连接、SQL 和数据均为隔离生成的样例。
- 原有 SQLite、PostgreSQL、MySQL、MariaDB 核心工作流及 SSH/TLS 支持保留。
  产品账号、产品登录、订阅和激活体系继续排除。

边界：本轮可编辑设计器仅支持 SQLite；其它三驱动的结构仍是只读元数据和 SQL 创建入口。
表达式/部分索引在 UI 中只读保留；virtual/无法安全解释的声明、外层事务、危险的 legacy ALTER
设置、混合重命名与其它修改等情况会拒绝保存并说明原因。与原版部分操作保留旧表副本的行为
尚不一致，不宣称这个里程碑已经完整还原表设计器。

Redis、Snowflake、Oracle、SQL Server、MongoDB、完整导入导出与传输同步、AI、数据分析/脱敏/字典、
数据库权限管理、自动运行、模型和 BI 等必需功能，继续由 `docs/parity-matrix.md` 逐项跟踪。
当前安装包没有发布者签名或 Apple 公证；Windows ARM64 安装引导器为 x86，应用及库为原生 ARM64。
Linux 安装包以 Ubuntu 24.04 构建验证环境为准。校验和与构建安装清单随版本发布。
