本里程碑增加实际 SQL Server 与 Redis 驱动、新版九类数据库连接选择器，以及 SQLite 独立索引和触发器设计。
Windows、Linux、macOS 的 amd64/arm64 六份安装包需全部通过原生安装门禁后发布。

- SQL Server 提供 SQL 认证、严格 TLS / SSH、T-SQL 批次、多结果、元数据、分页和记录编辑、事务及取消。
- Redis 提供单机 ACL 认证、原生命令、SCAN、六种基本类型、字节编辑、TTL、原子新建和修改冲突保护；编辑页按实际参考使用上下分栏。
- 新建连接显示九类数据库与供应商筛选、搜索、图标/列表和 URI。Oracle、MongoDB、Snowflake 驱动仍待接入，入口明确显示状态。
- SQLite 独立索引/触发器对象列表与设计页支持实际 SQL 预览和确认保存，保护系统索引、依赖、待提交记录及取消流程。
- 新增 macOS Navicat 18 历史连接自动发现、分组与本地修改保护，源文件只读、不会自动连接业务数据库；已保存密码需重新补充，Windows/Linux原生资料迁移仍待完成。

模型、BI、AI 等开放门禁没有被本里程碑取代。安装包仍未签名或 Apple 公证，Windows ARM64 引导程序为 x86、应用与库为原生 ARM64。
