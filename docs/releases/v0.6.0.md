本里程碑接入 MongoDB：从连接设置、集合浏览到 BSON 文档编辑、原生命令查询和 GridFS 文件工作区。
Windows、Linux、macOS 的 amd64/arm64 六份安装包全部通过原生安装、运行和卸载门禁后发布。

- Standalone 支持无验证、密码 SCRAM 默认协商/SHA-1/SHA-256、认证库、TLS 和 SSH；提供严格 URI 解析。
- 集合和视图使用独立的 BSON 网格、树及 Canonical Extended JSON 展示，保留 Int64、Decimal128、Binary、日期等精确类型。
  文档替换和删除检查原始前像、集合身份与会话，冲突时保留草稿；无法证明无损往返的内容保持只读并允许原始 BSON 导出。
- 查询页执行原生 BSON 命令及已实现的 shell 语法片段，支持多结果、实际部分写入结果、游标分页与取消。
  整段脚本先预验证，取消后不执行下一条命令；未确认的 `w:0` 写入明确拒绝。
- GridFS 提供九列元数据、筛选、分页、后台上传/下载/删除、进度与独立传输取消，以及小于 1,000,000 bytes 的有界图像预览。
  上传创建新文件版本，下载核对内容后提交且默认不覆盖已有目标；standalone 多文档清理失败明确报告。
- 主窗口按 MongoDB 切换分类、工具栏、索引列表与集合统计；连接和对象支持 Return/数字键盘 Enter 打开。
- README 保留一段 OpenNavicat 实际录制的 GIF，展示生成的 SQLite 与 MongoDB 示例数据，不含用户存量连接或业务数据。

SQLite、PostgreSQL、MySQL、MariaDB、SQL Server、Redis 继续保留，产品账号、登录、订阅和激活体系继续排除。
macOS Navicat 历史连接可只读自动加载，保留分组、去重与本地修改；不自动连接数据库，不迁移已保存密码。
Windows 原生历史连接发现、Linux 的完整迁移兼容仍待完成。

本版仍是持续迭代的预发行里程碑，完整 1:1 UI 与数据库工具目标继续推进。
MongoDB 完整 JavaScript/mongosh 引擎、当前单文档树编辑及记录导航、可视查询/聚合构建器、专用集合/索引设计器、SRV/副本集/分片、
非 primary 读取和其它认证方式尚未完成；GridFS 外部应用打开仍禁用。
Oracle、Snowflake 适配器以及更完整的同步、备份、模型、BI、AI 等门禁仍开放。
六份安装包仍未签名或 Apple 公证；Windows ARM64 安装引导器使用 x86，应用及其库为原生 ARM64。

完整验证范围、失败修补与证据边界见 [0.6 验证记录](https://github.com/shubolab/opennavicat/blob/main/docs/validation-0.6.md)。
