本里程碑继续对照本机 Navicat Premium 18.0.5 build 321，改进 MongoDB 文档工作区和历史连接加载。完整 1:1 UI 与全部数据库工具目标继续推进。

- MongoDB 树视图现在显示当前一份文档的字段、值和精确 BSON 类型。切换网格、树和 Extended JSON 保持选中记录；记录导航支持当前页和已实际读取的跨页边界。字节上限造成的短页不会按固定行数跳过文档，未知总数时不猜最后一页。
- 未保存编辑在导航前提供保存、放弃和取消。树字段双击打开既有的 Extended JSON 编辑器；类型 popup 与原版行内编辑仍待实现。
- 修复取消离开脏稿后的行高亮与实际文档可能不一致的问题，覆盖鼠标、方向键、双击和异步保存期间的编辑目标。
- GridFS 图像预览和传输进度移至列表与分页下方，各自独立开关；右侧全局信息栏保留独立状态。
- Windows 普通启动可只读发现当前用户注册表中的 Navicat 连接候选，显示为待复核配置。仅查询明确白名单的非秘密字段，不读取或解密密码、私钥、opaque 设置，也不自动连接。来源认证、TLS/SSH 和 Windows 18 实际格式未完成原版验收，确认设置前保持阻止连接。
- 重载来源时，不完整读取保留已有连接配置和分组；双注册表视图只在取得当前原生别名证据时调和身份，并保留本地修改、收藏与秘密。
- 连接和 SSH 端口输入框按原生字体与样式计算宽度，改善大字体下的数字裁切。
- README 保留一段 0.7.0 实际录制的 GIF，展示隔离生成的 SQLite、MongoDB 和 GridFS 示例。

现有 SQLite、PostgreSQL、MySQL、MariaDB、SQL Server、Redis、MongoDB 核心驱动继续保留。产品账号、登录、订阅和激活体系继续排除；数据库认证与权限工具仍在完整目标内。macOS 历史来源沿用已有支持，Linux 18 原生格式与 Windows 18 save-only 样例仍待继续验证。用户现场 Windows 补充 GUI 验收按要求延期，原现场保留，不作为本版已完成验收。

本版仍为预发行里程碑。完整 JavaScript 引擎、MongoDB 可视查询/聚合构建器、集合/索引设计器、更多拓扑和认证，以及 Oracle、Snowflake 和其余完整工具门禁仍开放。六份安装包未配置发布者签名或 Apple 公证；Windows ARM64 的安装引导器为 x86，安装后的应用和原生库为 ARM64。Linux DEB 需要 Ubuntu 24.04 / glibc 2.39 或更新环境。

六份实际安装包须全部通过原生测试、打包、安装、运行、卸载和数据库安全门禁才公开发布。验证范围与结果见 [0.7 验证记录](https://github.com/shubolab/opennavicat/blob/main/docs/validation-0.7.md)。
