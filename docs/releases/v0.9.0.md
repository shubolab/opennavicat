# OpenNavicat v0.9.0

本里程碑增加 MongoDB JavaScript 索引 helpers，并修复连接设置在异步保存设计文档后丢失的问题。
正式安装与公开资产的实际验证结果见 [0.9 验证记录](https://github.com/shubolab/opennavicat/blob/main/docs/validation-0.9.md)。

完整 Navicat 工具和三平台 1:1 界面仍在实现；产品账号、产品登录、激活、订阅和云账号协作继续排除，数据库认证、权限和云数据库仍保留。

## 本轮变化

- 内置 MongoDB 集合对象新增八个索引 helpers：`createIndex`、`createIndexes`、`ensureIndex`、`getIndexes`、`getIndexSpecs`、`getIndexKeys`、`dropIndex`、`dropIndexes`。
  支持已实现的有序键、常见索引选项和明确控制参数，未知选项拒绝，不静默丢弃。显式 BSON 构造器保持其已验证类型；普通 JavaScript Number 仍使用 Double。
- 读取索引通过受管理的原生游标/会话，超过交付预算明确报错，不返回假完整数组。写 helpers 沿用父端只读及命令校验，服务器权限仍适用；数据库会话、凭据和传输不进入 JS 子进程。
- 已收到的服务器错误保留 `code` / `codeName`，区分收到错误回复、已确认写入和确认未知。缺少服务器影响数量时保持 unknown，不把 DDL 当成行修改来计数。
  前面的成功写入不会因后面的失败自动回滚；JS 捕获错误后可以正常完成脚本，但命令回执和警告仍保留。
- 修复设置窗口已经接受并关闭后，脏设计文档的异步保存只完成断开、却丢弃新连接设置的问题。
  原会话确实关闭后才采用已捕获的新配置和凭据保存选择；取消、保存/关闭失败、较新编辑或窗口关闭撤销旧操作，不重开设置窗口。
  手工连接按原行为重连，Navicat 导入连接继续等待用户手动打开；不新增自动连接来源数据库的行为。

## 操作与兼容边界

`createIndex` 成功返回单个索引名，`createIndexes` 和 `ensureIndex` 返回名称数组；三个 `getIndex*` helpers 返回对应的定义/键数组；删除 helpers 返回服务器结果文档。
`dropIndex('*')` 和数组参数拒绝，批量操作使用 `dropIndexes`；**省略 `dropIndexes` 的选择参数表示全部可删除索引**，服务器继续保护默认 `_id` 索引。

这些 helpers 按集合名操作，不等于设计器“执行脚本（集合 UUID）”的身份保护。多条索引 DDL 不是事务；不承诺原子 CAS、自动重试或失败回滚。只读限制和服务器权限仍分别适用。

对照使用独有 MongoDB 8.0.34 中的实际 mongosh 2.14.0，仅检查已执行的返回形状、选项及错误。
**原版 Navicat 18 的这八个 helpers 仍未实际观察**，不能把 mongosh 等同 Navicat，也不声称完整 shell、Node、原版全局/API 或 BSON 运算透明兼容。
副本集 quorum、分片、正在构建的索引、Atlas Search 和完整认证/拓扑仍有未验收范围。
丢确认和 concern-error 的注入测试会明确标为注入，不把它们当作实际副本集或网络故障资格。

## 安装与发布门禁

发布门禁要求 Windows、Linux、macOS 的 amd64/arm64 原生主机分别完成源码、冻结、实际安装/运行/卸载与严格 helper 探针，且独立数据库安全任务通过后才公开版本。
提供六份 EXE、DEB、DMG 安装器及 `SHA256SUMS`、`build-manifests.json`；旧 0.8.1 安装结果不能替代本版验收。
源码使用原生 JS 前需先构建固定来源 helper；安装包随包分发，不在用户查询时下载或编译。

安装包仍为无发布者签名/Apple 公证的早期预发行。Windows ARM64 安装引导器使用 x86，安装后的应用和原生依赖为 ARM64。
Linux DEB 基于 Ubuntu 24.04，要求 glibc 2.39 或更新，并通过包管理器安装声明的 Qt 图形库与字体。

用户 Dell Windows/RDP 与无桌面 WSL GUI 验收继续延期，现场保持原状。完整功能及 UI 门禁仍见[对齐矩阵](https://github.com/shubolab/opennavicat/blob/main/docs/parity-matrix.md)，不因本版发布而关闭。
