# Navicat 1:1 UI 与完整工具功能路线

用户已明确校正目标：**Windows、Linux、macOS 三个平台上的 1:1 Navicat UI，以及完整数据库工具功能**。参考对象是本机 Navicat Premium；已确认的本机版本为 16.1.1 build 51。现有自定义工作台是部分实现，不能作为目标 UI 或完整交付标准。

排除 Navicat 产品账号、产品登录/注册、激活、订阅/商业授权和 Navicat 云账号/团队账号协作系统。数据库连接认证、数据库用户/角色/权限、云数据库连接及其别名入口全部保留。参考支持的云数据库认证仍属于数据库功能。文件式本地查询、配置、模型、备份、任务管理也保留。移除排除的产品账号区域，不构成重新设计其它工具 UI 的理由。

完成条件由[完整对齐矩阵](parity-matrix.md)管理。以下阶段只决定工作顺序，不会把后续阶段降为可选项，也不会把“可运行核心版本”改称完整 OpenNavicat。

## 阶段一：实际参考与封闭清单

- 使用为任务新建的 SQLite 和一次性数据库服务，在实际 Navicat 中逐项观察；不读取既有用户连接、密码、工作区或生产库。
- 记录主窗口、工具栏、菜单、连接树分类、对象列表、信息面板、对话框、设计器、向导和所有禁用/错误/执行状态。静态资源提供入口线索，运行观察确认行为。
- 逐层枚举七个原生驱动及云数据库别名中的所有适用功能：MySQL、PostgreSQL、Oracle、SQLite、SQL Server、MariaDB、MongoDB。
- 将新发现入口补入矩阵，关联实际截图/操作记录、fixture 和验收结果。尚未观察到的格式、选项和驱动限制保留为开放问题。

## 阶段二：主窗口及基础工作流 1:1

- 还原实际 Navicat 的窗口分区、原生菜单和工具栏分组。已观察主工具栏为连接、新建查询、表、视图、函数、其它、用户、查询、备份、自动运行、模型、图表；可用状态随活动连接和驱动变化。
- 还原表/视图/查询/备份等导航分类、对应对象列表、可选信息面板，以及筛选、排序、列、图标、右键、双击与布局持久化。
- 逐个还原连接设置、SQL 编辑器、结果、表数据窗口、现有表设计器及基础向导。样式与真实数据库语义分别验收。

## 阶段三：全部驱动、对象与安全管理

- 补齐 Oracle、SQL Server、MongoDB 和参考所列云数据库连接；四个已有驱动仍须补齐连接选项、SSH/HTTP 隧道、完整 TLS、认证及适用高级设置。
- 按驱动补齐数据库/schema、表、索引、约束、外键、视图、触发器、函数、过程、序列、事件、物化视图等对象的可视化管理；通用 SQL 执行不能替代这些工具。
- 补齐 PostgreSQL 扩展/类型/外部对象、Oracle 包/链接/回收站/Data Pump、SQL Server 特有对象及 MongoDB 集合/文档/索引/GridFS 等实际参考能力。
- 补齐数据库用户、角色、登录和权限管理，用低权限用户验证允许/拒绝行为。只有参考行为及服务版本证据可将某驱动功能标为不适用。

## 阶段四：完整数据与查询工具

- 补齐数据网格、记录/辅助编辑器、条件筛选/查找/排序、完整类型处理、可视查询构建器、参数/代码片段/补全、解释计划、调试与后端脚本工具。
- 逐项还原导入/导出向导的所有格式、映射、编码、预览、执行日志和配置保存。CSV/JSON 通路仅是部分实现。
- 补齐 SQL 转储/执行、跨连接数据传输、结构同步、完整数据同步和数据生成。现有比较要求相同列名/主键且每表上限 10,000 行，不代表完整同步工具。

## 阶段五：建模、备份、自动运行与分析

- 完成概念/逻辑/物理模型的持久化编辑、正向/逆向工程、转换、同步到数据库、SQL/图片/打印输出及参考支持的辅助对象。只读关系图不是完整模型功能。
- 补齐各数据库适用的备份、还原、转储、原生服务端工具及 Oracle Data Pump；SQLite 快照不能代表全部备份功能。
- 完成批处理、自动运行、计划、执行记录、失败/取消/重启恢复及配置复用。
- 完成图表工作区、数据源、图表/仪表盘设计和本地保存/导出；排除产品账号和云账号不会将这些工具移出范围。
- 补齐服务器监控、维护、数据库搜索及各驱动实际支持的管理工具。

## 阶段六：三平台验收与交付

- 逐项运行矩阵的 UI 对照与数据库功能 case，保留正确/错误/取消/重启证据；用独立连接或原生工具核对最终数据、schema 和权限。
- Windows、Linux、macOS 实际打包应用均需完成对应平台验收；窗口、菜单、字体、DPI、快捷键和原生文件选择器依据该平台参考对照。
- 补齐安装/升级/卸载、签名/公证、干净机器、密钥服务、可访问性与性能。CI 配置、测试、构建、smoke、UI 对齐和完整功能验收分别记录。

## 现有成果的使用方式

首个可用里程碑 [v0.3.0](https://github.com/shubolab/opennavicat/releases/tag/v0.3.0)
提供六个原生目标的安装包。已有四驱动核心、SQL 工作区、主键数据编辑、CSV/JSON、元数据、
有限比较、只读关系图、SQLite 快照，以及 SSH/TLS 连接可作为继续开发的基础。
[0.3 验证记录](validation-0.3.md) 区分原生安装验收、实际数据库安全测试和仍未通过的完整对齐门禁。

按用户要求，本次交付后暂停，等待用户更新本机 Navicat 并明确恢复。恢复时先执行
[新参考确认与交接步骤](resume-after-first-release.md)，不直接把 16.1.1 的观察套用到新版。

只有矩阵清单封闭、所有适用 UI/功能门禁和三个操作系统验收全部通过，才能声明目标完成。
