## 阶段一：新版实际参考与封闭清单

- 使用为任务新建的 SQLite 和一次性数据库服务，在实际 Navicat 中逐项观察；不读取既有用户连接、密码、工作区或生产库。
- 记录主窗口、工具栏、菜单、连接树分类、对象列表、信息面板、对话框、设计器、向导和所有禁用/错误/执行状态。静态资源提供入口线索，运行观察确认行为。
- 逐层枚举九个数据库族及云数据库别名中的所有适用功能：MySQL、PostgreSQL、Oracle、SQLite、SQL Server、MariaDB、MongoDB、Snowflake、Redis。新版已实际展开14供应商节点，仍须以root另档的新运行清单逐项确认别名、设置和兼容后端。
- 将新发现入口补入矩阵，关联实际截图/操作记录、fixture 和验收结果。尚未观察到的格式、选项和驱动限制保留为开放问题。
- [18静态参考](reference-18-static.md)提供23类工具、本地手册和定向档案线索。原根64档案上限及29个定向副本都不是完整UI图，不以静态页面或文件名认定运行成功、能力删除或清单已封闭。
- 本轮root已实际观察主窗口BI/信息-AI切换、SQLite七页设计器并实建与重命名核验、查询消息/摘要/多结果/数据分析、Tools脱敏/字典，以及新的连接选择窗口。这些是新参考的有界运行事实；完整错误/取消/持久化、其它驱动和OpenNavicat对应行为仍需验收。

- 按18实际窗口重新还原分区、原生菜单和工具栏分组，包括BI和信息/AI共享侧栏；不继续把16的工具栏文字/连接dropdown当成新版目标。可用状态随活动连接、驱动和工具能力变化。
- 0.5已接入macOS Navicat18历史连接自动发现、分组与本地编辑保护；继续完善原版密码合法迁移及Windows/Linux原生来源，不能把未知安全设置猜成默认配置。
- 还原新的连接选择窗口：供应商过滤、九驱动、图标/列表、搜索、URI入口和进入设置的过程；连接管理器、星标/隐藏、导航过滤/定位/折叠与持久化也单独对照。
- 还原表/视图/查询/备份等驱动分类、对象列表列/排序、信息/DDL/依赖和Objects的Detail/ER Diagram。新版ER图有外键编辑/删除、布局/颜色/输出，现有只读关系图不等价。
- 先把SQLite七页设计器、SQL消息/摘要/多结果和表数据工作流做成实际可用闭环，再扩展其它对象与向导。逐页保留默认值、SQL预览、失败/取消和重启状态；参考实建成功不表示新实现已经通过。

## 阶段三：全部驱动、对象与安全管理

- 补齐Oracle、Snowflake和参考所列云数据库连接；SQL Server与Redis在0.5已有真实核心适配，MongoDB在0.6开发分支接入standalone、类型保持文档读写与原生工作区。各驱动仍须补齐全部拓扑/选项/认证/HTTP及适用高级设置。0.3已通过真实SSH/TLS核心测试，保留该基础，同时完成18参考及全部驱动/平台的安全选项对照。
- 按驱动补齐数据库/schema、表、索引、约束、外键、视图、触发器、函数、过程、序列、事件、物化视图等对象的可视化管理；通用 SQL 执行不能替代这些工具。
- 补齐PostgreSQL扩展/类型/外部对象、Oracle包/链接/回收站/Data Pump、SQL Server专属对象及MongoDB普通/时序集合/文档/索引/GridFS等实际参考能力。
- Snowflake覆盖Standard/Hybrid/Dynamic表、warehouse/role/namespace、原生客户端依赖及DB MFA/SSO；Redis覆盖Sentinel及适用拓扑、key类型/TTL/数据库、ACL的command/key/channel规则。不能用普通关系型表格或只改连接名称代替专用工具。
- 补齐数据库用户、角色、登录和权限管理，用低权限用户验证允许/拒绝行为。只有参考行为及服务版本证据可将某驱动功能标为不适用。

## 阶段四：完整数据与查询工具

- 补齐数据网格、记录/辅助编辑器、条件筛选/查找/排序、完整类型处理、可视查询构建器、参数/代码片段/补全、解释计划、调试与后端脚本工具。
- 逐项还原导入/导出向导的所有格式、映射、编码、预览、执行日志和配置保存。CSV/JSON 通路仅是部分实现。
- 补齐 SQL 转储/执行、跨连接数据传输、结构同步、完整数据同步和数据生成。现有比较要求相同列名/主键且每表上限 10,000 行，不代表完整同步工具。
- MongoDB独立`.nagg` Pipeline需有stage图、阶段编辑/顺序/开关、输入输出预览、脚本/Explain/执行/取消/导出与自动任务引用；与旧Find/Aggregate Builder分别验收。
- 增加Data Profiling的扫描/过滤范围、列质量/分布/统计、spotlight和结果定位，以独立计算核对。Mongo/Redis等未列入手册的适用性继续调查，不能自行启用或永久删去未知项。
- 增加Data Masking的转移与原表两条流程、Substitution/Variance/Hashing/Nulling/Shuffling、事务/批次/失败和profile；仅使用一次性数据验证实际副作用。
- 增加Data Dictionary的连接/对象顺序、模板与版面、输出/日志/profile，独立解析并视觉检查输出；完整导入导出、生成/同步等向导不能因该新增工作被降为可选。

## 阶段五：AI辅助与独立provider配置

- 实现参考支持的provider、OpenAI-compatible和本地provider入口，名称/endpoint/key/model/参数/行为/测试及秘密存储；不做Navicat产品登录、订阅或配额系统。
- 实现AI Chat及schema/tab上下文、比较回复/分叉、Ask/Fix/Explain/Optimize/Format/Convert和编辑器插入；保留建议预览、明确应用、取消/错误/撤销和连接绑定。
- 覆盖AI建表/注释、Fill with AI的源/目标字段、当前页/自定义范围/新行、建议预览和应用。使用全合成样例与可控测试provider验证协议和写入；未经选择的用户连接或数据不得被收集。
- provider、模型能力、平台/驱动/服务版本等依赖逐项记录。暂时没有凭据或未观察某能力，不构成删除该功能的理由。

## 阶段六：完整模型、BI、备份、自动运行与运维

- 完成概念/逻辑/物理/Hybrid模型的持久化编辑、Relational/Dimensional/Data Vault方法、模型/图复用、Glossary/Naming Standard/Bulk Editor/数据字典、workspace比较、SQL或DB反向工程、正向工程及双向同步。只读关系图不是完整模型功能，文件关联也不证明旧模型格式兼容。
- 补齐各数据库适用的备份、还原、转储、原生服务端工具及 Oracle Data Pump；SQLite 快照不能代表全部备份功能。
- 完成批处理、自动运行、计划、执行记录、失败/取消/重启恢复及配置复用；新版管线/脱敏/字典等profile按实际适用范围加入，不能假定所有工具皆可计划。
- 按新版BI工作区完成数据库/文件/ODBC/跨源数据集、Live/Archive、join与处理管线、计算/映射字段、参数和数据分析，进而覆盖全部图表、主题、互动控制、多页仪表盘、本地保存/导出/打印。旧Charts原型或一条SQL不能代替BI数据设计器。
- 补齐服务器监控、维护、数据库搜索及Redis Command Monitor、Pub/Sub发布/订阅/消息归档/profile/断线恢复等实际工具；Redis备份还原和ACL与关系库工具分开验收。
