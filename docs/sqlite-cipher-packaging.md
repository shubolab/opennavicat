# SQLite cipher runtime packaging

2026-11-15. This leaf adds the exact `apsw-sqlite3mc==3.54.0.0` runtime dependency and a mandatory owned-file probe. The ordinary `apsw` distribution must not overlap it. The standard backend is not selected or changed by this packaging work.

PyInstaller explicitly includes `apsw`, `apsw.ext` and the distribution metadata. The probe creates a new AES256 encrypted file, writes two bound rows in an explicit transaction, closes and reopens it read-only, runs quick_check, rejects a wrong key and standard SQLite, checks unchanged bytes after reads, and removes its temporary directory. Missing or mismatched native providers fail instead of skipping. Source, frozen and installed smoke invoke the same probe. The existing SQL rows, JS, Oracle, TLS and native target checks remain.

All five SQLite cipher notice files are checked against fixed SHA256 values in source and frozen smoke. Setuptools retains them in wheel metadata and PyInstaller includes them under `licenses/`. The exact distribution source contains additional notices beyond the wheel's APSW notice: SQLite3MC MIT, SHA2 BSD-3-Clause, Argon2/Blake2 CC0-or-Apache-2.0, fastpbkdf2/encoding CC0, AEGIS MIT, public-domain declarations, and miniz MIT/Unlicense notices. Original notices and full Argon2/Blake2 license texts are retained. [Sources and hashes](evidence/sqlite-cipher-license-sources-3.54.0.0.json) identify the exact sdist and pinned upstream license source. Nothing comes from Navicat libraries or resources.

Local macOS arm64 validation passed 249 packaging/probe/installer/release contract tests with no skips. The source probe, a source-independent installed Python wheel, an actual PyInstaller application, and an isolated DMG install/launch/uninstall all passed. The DMG's owned installation directory and mount were independently confirmed absent. The app ran with offscreen QPA and retained version **0.13.3**: these are development-artifact results, not 0.14 native version-gate or reference UI acceptance. The >=0.14 installed/publish gate branches passed synthetic contract tests; the actual installed cipher receipt was additionally validated directly. [Local receipt](evidence/sqlite-cipher-packaging-macos-arm64.json) records source and evidence hashes.

The existing six-target workflow now executes the source cipher probe and retains its JSON before its unchanged full default suite, application build, packaged smoke and native installer checks. The new workflow has not yet supplied six-target native results. Windows/Linux and macOS amd64 execution, final integrated 0.14 source, installers and reference-backed feature/UI parity remain open.
