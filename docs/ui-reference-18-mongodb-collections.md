## MC18-01：新建与重开普通集合的七页顺序

在新建的样例数据库点击对象列表“新建集合”，普通集合设计器直接在主工作区打开。
新建状态默认选择“索引”，实际顺序为：

1. 索引
2. 验证
3. 存储引擎
4. 索引选项
5. 集合选项
6. 排序规则
7. 脚本预览

保存后关闭，再从对象列表“设计集合”重开，仍是上述七页、默认“索引”。
这两个已观察状态没有“原始 BSON”“字段”或“外键”页。
这个事实只适用于本轮普通集合和服务器状态；不能删除其它版本、对象或状态的未知适用性。
静态资源中的同名模块存在，不构成它们在此状态下可达的证明。

索引页工具条为“保存、 新建索引、 删除索引、 进入/退出专注模式”。
验证页改为“保存、添加属性、删除属性、专注模式”；脚本编辑页改为
“保存、询问 AI、专注模式”。本轮没有调用 AI。

## MC18-02：内嵌索引表和独立索引设计器并非同一交互

内嵌表仅有前导图标列以及 **名称、键** 两个具名列，下面另放：

- 唯一键、背景、稀疏复选框。
- 在此之后过期（秒）复选框及输入框。
- 存储桶大小输入框。

无选中行时上述设置禁用；选择已有的合成非默认索引名称单元格后设置启用。
本轮普通、非 unique、非 sparse、无 TTL 的索引相应复选框均为未勾选，输入为空。

“新建索引”在本页增加一个**未保存的内嵌草稿行**，并非打开完整独立索引设计器。
键单元格提供一个按钮，打开另一个模态键编辑器；其中列为“名称、类型”，
操作为“添加、移除、好、取消”。类型列表实际展开为
`ASC / DESC / 2D / 2DSphere / Hashed / Text`。

本轮内嵌草稿的名称、键曾出现 AX 显示值已改变但最终脚本仍含空方向的状态。
因此未执行该草稿，而是关闭时选择“不保存”；不能将 AX 设置成功当成模型已提交。
独立 PyMongo 确认该草稿索引没有写入服务器。
内嵌索引增改删的完整保存次序、错误、取消和恢复仍需继续实测。
已有[独立索引观察 M18-07](ui-reference-18-mongodb.md)
不能替代这条内嵌路径。

### `_id_` 在本轮内嵌表中没有显示

最初创建空普通集合成功后，直接切换到索引页显示空表；关闭并重开后也为空。
独立 PyMongo 同时确认服务器已有 `_id_`，实际 catalog 的 `idIndex` 也存在。
随后用独立 PyMongo 在同一自有集合创建唯一命名的非默认测试索引，再刷新对象列表、
重开设计器，内嵌表仅显示该非默认索引及 `label ASC`；信息栏的索引数为 2。

这证明在本轮状态中“内嵌表未显示 `_id_`”与“服务器没有 `_id_`”是不同事实。
不能将新建后自动补入 `_id_` 行称为已还原的原版行为。
本轮没有推断所有服务器版本或其它索引类型均采用相同隐藏规则。

## MC18-03：验证页默认值与嵌套布局

新建普通集合实际显示：

| 项目 | 初始显示 | 本轮实际展开的选项 |
| --- | --- | --- |
| 验证级别 | 空白组合框 | `off`、`strict`、`moderate` |
| 验证动作 | 空白组合框 | `error`、`warn` |
| 验证符类型 | `JSON Schema` | `JSON Schema`、`Query` |

不能把服务器的隐式 strict/error 默认值写成这两个控件的初始显示值。
默认 JSON Schema 下还有“属性、根模式”两个子页，初始为“属性”。
属性空表的具名列为“名称、BSON 类型、必需、标题、描述”，表下还有分隔器及属性区。

本轮没有新增 schema 属性或提交 validator，没有展开各 BSON 类型的属性编辑面，
也未完成 Query 模式、验证错误、保存和重开闭环。这些仍是功能与 UI 的开放门禁。

## MC18-04：存储引擎与索引选项属于集合创建选项

两个页面各自是带行号的脚本编辑区；本轮新建及普通已有集合的初始文本均为空。
已有集合的两个编辑区尝试粘贴后未出现内容或 dirty 状态变化；本轮仅记录这次观察，
不将其推广为所有已有集合或服务版本的可编辑性结论。

在另一个未保存的新建草稿中，实际输入合成对象并切换到脚本预览，取得：

```javascript
db.createCollection("Untitled",{
    storageEngine: {
        wiredTiger: {
            configString: "block_compressor=zstd"
        }
    },
    indexOptionDefaults: {
        generated_probe: true
    }
})
```

其中 `storageEngine` 来自“存储引擎”页，`indexOptionDefaults` 来自“索引选项”页。
它们是**集合级创建选项**；并非当前所选索引行的完整高级选项编辑器。
这段仅是实际 UI 的草稿脚本投影；`generated_probe` 是故意生成的观察值，
没有提交服务器，不能据此宣称它是有效 MongoDB 选项。
该草稿最终“不保存”关闭，独立读取确认已有集合 options 仍为 `{}`。

## MC18-05：集合选项的默认值和联动

新建普通集合实际可见以下选项：

| 控件 | 本轮新建初始状态 |
| --- | --- |
| 固定集合 | 未勾选 |
| 最大大小（字节）、最大文档数量 | 依赖固定集合；勾选后出现可编辑空输入 |
| 聚集集合 | 未勾选 |
| 聚集索引名称 | 依赖聚集集合；勾选后可编辑空输入 |
| 在此之后过期（秒） | 未勾选且初始禁用；勾选聚集集合后启用 |
| 更改流前图像和后图像 | 未勾选 |
| 自动索引 ID | 已勾选 |
| 使用 2 的次方的大小 | 已勾选 |
| 无填充 | 未勾选 |

本轮实际勾选/取消固定集合、聚集集合和过期控件，最后恢复初始选择；
其后新建预览仍仅为 `db.createCollection("Untitled")`。
不能将复选框的默认勾选等同于原版总是向 MongoDB 8 发送旧选项。

重开已有普通集合时，固定集合、聚集集合、过期以及自动索引 ID 显示禁用；
更改流前图像和后图像、使用 2 的次方的大小、无填充仍显示可操作。
本轮没有保存这些选项，尤其没有验证旧选项在 MongoDB 8 的服务器接受行为，
也未验证聚集集合、capped、change-stream 的实际 DDL。

## MC18-06：排序规则和脚本预览

排序规则页的区域设置初始为空、可选择；其它八个初始为空且禁用：
大小写级别、大小写优先、强度、数值排序、替代、最大变量、逆向、规范化。
本轮没有展开所有区域设置或验证联动值及实际 collation 创建。

脚本预览含“更改、DDL”切换，默认更改，脚本区域只读并带复制按钮。
空新建集合的更改脚本使用占位名称 `Untitled`，而标签标题中文显示“无标题”。
成功保存后更改区显示“无更改”。本轮没有完整核验 DDL 模式在每种状态的内容。

## MC18-07：命名、取消、普通创建和重开

普通新建集合点击“保存”后打开名称 Sheet，实际标签为 **“表名称:”**，
同时显示脚本预览以及默认未勾选的“不再显示脚本预览”复选框。
空名称时保存按钮禁用；输入名称、结束编辑后，预览中的 `Untitled` 同步为该名称。

本轮完成两个独立结果：

1. 输入合成取消名称后点取消：Sheet 关闭、原草稿保留；独立 PyMongo 确认没有新增集合。
2. 再次保存并命名 `ordinary_probe`：最终预览仅为该精确名称的 `db.createCollection`，
   保存成功后标题更新、更改区为“无更改”；独立 catalog 确认为 ordinary collection，
   options 为 `{}`，文档数 0，自带 `_id_`。随后关闭、从对象列表“设计集合”重开成功。

没有修改“不再显示脚本预览”偏好；没有通过原版删除、清空数据库对象。
关闭后续未提交的索引/存储草稿时实际出现“保存、不保存、取消”提示，并选择“不保存”。
