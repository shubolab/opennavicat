## 当前接入

成功、复制和关闭使用独立绘制，裸加减与圈加号保持不同语义。共享结果条在 GUI 线程绘制
当前 DPR 的图形，状态、详情按实际字体裁切省略；显示和 tooltip 各限制 512 字符，复制
内容单独限制 1024 字符。长版本文字不会把窗口撑宽。已修复颜色样式导致动态字体继承失效，
普通、失活和禁用文字分别使用对应状态。

SQLite 通过原有串行测试 worker 真实读取 `sqlite_version()`，会话仍由该 worker 关闭；返回
不可变的文字数据，公开 `test_finished(True, "连接成功")` 保持原协议。成功条和 44px 底栏
放在设置列，取消/保存实际按钮位于末端。成功后仅连接线变绿；重测、失败、驱动或连接设置
变化会清除旧反馈。现有 Oracle worker 与独立绘制的连接图不改用 SQLite 状态。

Oracle 数据库页三个文字按钮改为灰色裸加减与刷新图形，保留本地增删回调、配置草稿、
自定义列表开关和未实现的获取功能禁用状态。测试条复用有界绘制；原 Oracle 成功复制内容
仍为 `✓  连接成功  服务器版本: ` 加原先限制的版本文字，视觉上的勾改为图形。

GridFS 条件加减和执行计划详情关闭按钮也替换了字体字形；这是原有控件的可缩放绘制接入，
尚未取得这些具体位置的参考图形验收。详情关闭或切换时清除成员、移出场景并 `deleteLater()`，
旧关闭信号按实际 proxy 身份校验，避免关闭新详情。没有新增数据库行为。

smoke 报告开始由实际 `QApplication.platformName()` 记录 `qt_platform_name`；读取在 GUI
主线程进行。这不回填 0.13.1 报告中未记录的实际平台，也不代表原生人工参考验收。
