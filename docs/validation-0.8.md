## Linux 历史连接：实际格式与保守迁移

实际参考版本分别为 Linux **18.0.3**、macOS **18.0.5 build 321**；Windows **18.0.6** 的相关材料属于官方/静态工件线索。Windows 自有 HKCU 测试验证注册表 API 与合成来源，不证明当前 Windows Navicat 18 的实际保存格式已经验收。不能用三者版本接近来推断存储格式相同。

Linux 实际格式观察使用断网、隔离 HOME 和自建样例的原版运行，仅保存配置，不测试或连接数据库。已观察 `Common/connections.json` 中的 `Users → Projects → Servers`、PascalCase 基础字段、七个已实现驱动的默认样例，以及分组和重启后的稳定身份。默认目录、绝对 XDG 路径和已知 Flatpak 候选的发现范围见使用文档；Flatpak 路径测试不等于实际 Flatpak Navicat 保存格式验收。

## MongoDB 索引设计与取消

已接入候选的工作流见 [MongoDB 索引设计器](mongodb-index-designer.md)：九列索引对象列表，独立六页设计文档，新建/已有索引保存预览，删除确认，脚本复制，实际命令状态和失败后重新读取，关闭/断开/恢复，以及只读与受保护索引。数据库工作仍通过主窗口串行队列，停止使用单独工作线程并绑定点击时捕获的操作身份。

实际参考为 macOS Navicat Premium **18.0.5 build 321**，只对自建临时集合写入。已实际验证保存窗口的“不再显示脚本预览”：勾选后取消不持久化；接受保存才关闭预览；之后修改同一已有索引不再出现保存预览。原偏好已恢复，临时集合已清理，原样例文档和索引未改变。最后返回原窗口/标签的操作发生工具超时，**最终 UI 位置未核实**；跨驱动作用域、重启、保存失败及新建索引的偏好行为仍开放。

独立索引分支的最终协议资格为 **254 passed、0 skipped、0 failed/error，51.13 秒**。其中需要真实 fixture 的 120 项，其余 134 项；collection 清单和结果均核验通过。七份新建、loopback、原生 ARM64 MongoDB **8.0.34** 容器的归属及最终删除全部核实。实际范围为会话、命令查询、既有主窗口、索引后端、六页组件、脚本序列化及索引主窗口七个模块，不包括完整 JS 引擎和最终六平台安装器。

首次协议运行是 **253 passed、1 failed**：既有主窗口测试仍硬编码旧的五列索引对象列表。按已实现九列修正该断言后才得到上述 254 项结果，首次失败保留。另有 **15 项真实主窗口 + 4 项离线停止回归**分别在 offscreen 和实际 Cocoa 执行，各 **19 passed、0 skipped**，用时 19.09 秒和 36.17 秒，均为 `-Werror`。早期索引源码 checkpoint 的全源 **1015 passed、353 skipped** 不含全部后续修补，不能作为当前候选的全源总数。

修改索引的删除/新建两步不是事务。集合 UUID 限定防止同名集合替换，但不是索引定义的原子 CAS。删除已确认而创建失败时，必须保留草稿、各步确认状态和实际索引状态；不自动重试、不把网络确认丢失解释为未修改。未知 BSON 选项不能无损编辑时保留原字节并只读，这仍是完整工具的缺口。

## 原生 JavaScript：进入候选前的独立资格

独立 `work/mongodb-js-engine` 的实现使用随应用分发的原生 QuickJS-NG 子进程和父进程 BSON/数据库桥，不通过 Python 求值脚本。父进程持有会话和凭据，逐命令执行只读和写关注校验；子进程只接收脚本、类型数据和执行限额。语言元数据区分旧受限命令模式与新的 MongoDB JavaScript，既有稿件/历史/收藏不根据扩展名自动改解释方式。

分支已有原生 helper、BigInt/BSON、进程取消回收、真实游标/会话、确认写入和部分失败、Qt 页面及持久化的资格证据。**这些不等于完整 mongosh/Node API，也不等于所有 BSON 值在任意 JavaScript 运算中都透明保真。** 不开放子进程文件/网络宿主 API 不代表已经建立 OS 级沙箱；进程隔离、限额和父端命令策略各有明确边界。

| `fe90ca8` 的全源 | **941 passed、356 skipped** | 不含本候选 Linux/索引的最终整合，不是 `723b227` 或下一合并提交的全源结果。 |
