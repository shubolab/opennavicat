## 原生 JavaScript：进入候选前的独立资格

独立 `work/mongodb-js-engine` 的实现使用随应用分发的原生 QuickJS-NG 子进程和父进程 BSON/数据库桥，不通过 Python 求值脚本。父进程持有会话和凭据，逐命令执行只读和写关注校验；子进程只接收脚本、类型数据和执行限额。语言元数据区分旧受限命令模式与新的 MongoDB JavaScript，既有稿件/历史/收藏不根据扩展名自动改解释方式。

分支已有原生 helper、BigInt/BSON、进程取消回收、真实游标/会话、确认写入和部分失败、Qt 页面及持久化的资格证据。**这些不等于完整 mongosh/Node API，也不等于所有 BSON 值在任意 JavaScript 运算中都透明保真。** 不开放子进程文件/网络宿主 API 不代表已经建立 OS 级沙箱；进程隔离、限额和父端命令策略各有明确边界。
