## 验收边界

独立绘制、实际控件接入、高分屏、主题、开关/禁用和连接状态需分别验证。
原型的通用圆柱、错误四格与图形语义差异必须修正，但同类图形并不等于 1:1。
仍需实际应用逐状态目视比较、失活窗口的主工具栏变灰行为、全部菜单/对话框/向导
小元素清点及 Windows/Linux 参考观察。Redis Enterprise Cloud 专属供应商符号尚未观察，不能用 Redis 数据库
符号冒充。U02/U03/U04/U09/U15 等完整门禁保留开放。

## 独立实现与冻结源码验证

当前图标集成源码冻结在 `211fef0ec0c7edbca2c016d0fd887e4acd977c90`，已推送
`codex_oracle_basic_integration`。主/对象绘制与小动作绘制分离；提供九驱动及十三个已观察
供应商图形。查询创建工具、解释、代码段、布局、专注、列、生成、脱敏、设置等入口
分别使用对应图形，不再依赖无关占位。未实现功能保持原禁用状态。

主工具栏 28、树/页签 16、查询选择器 14、连接网格 50/列表 16 逻辑像素分别接入。
连接与数据库开关使用独立状态；导入别名一起更新，未知驱动保留元数据与阻止提示但不
伪造数据库图标。刷新图标不重建选择器，不触发 SQL 或数据库工作。普通/活动/选中模式
保持原色，禁用单独变暗；开关的蓝/灰与禁用分开。高 DPI 直接重绘几何，像素缓存限制
为 256 项/32 MiB。
